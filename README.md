# Krysti Horvat — Personal Site

The website for **krystihorvat.com**.

This is a simple, static website: plain HTML, CSS, and images. There is no
software to build or maintain, no database, and no monthly platform fee. It is
designed to be hosted for free on **GitHub Pages**.

## What's here

| Page | File |
|------|------|
| Home | `index.html` |

- `assets/style.css` — the site's styling.

## How to make a change

1. Open the relevant `.html` file in any text editor (or ask Claude Code).
2. Edit the text between the tags.
3. Save, commit, and push to GitHub — the live site updates automatically.

## Hosting

Hosted on GitHub Pages, repo `kitchen401/krysti-horvat-personal-site`. The
custom domain (krystihorvat.com) needs to be pointed here via DNS — the domain
is registered and currently hosted through Wix. See the project notes for the
step-by-step domain switch.
